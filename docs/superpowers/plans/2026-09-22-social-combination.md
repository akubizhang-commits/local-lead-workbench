# 社媒组合采集实施

用户已批准浏览器试点、Instagram 开源工具对照、YouTube 官方接口及后续增量更新的组合方案。

实现范围：独立且私有的 Instagram/Facebook 浏览器配置目录；用户手动登录、不由系统代填密码；浏览器读取公开/用户会话可见的账号简介及有限近期帖子，失败明确标注。按平台配置读取器，保留原 HTTP 路径。可选 Instaloader、YouTube API 适配。账号归属仍人工确认，字段候选不自动成为采购人员；不发送消息。

配置与 API：独立 /social/connections；凭据只写本地权限0600文件，不进入队列快照或响应。浏览器 session open/close 状态不等于登录有效。会话文件锁避免登录窗口与 Worker 同时操作同一配置目录。任务复用已有持久队列、取消和历史模型。采集帖子按规范 URL 去重关联。

验证：配置边界/凭据隐藏/读取器路由/取消保护/备份社媒任务保护测试；提供者用模拟接口验证解析；完整 Python 与前端回归；本地运行依赖检查及真实公开页面小样本，登录后的实际验收交用户操作。
