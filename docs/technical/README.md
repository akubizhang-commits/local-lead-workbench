## 机器可读附件

- [OpenAPI 快照](openapi.current.json)：从临时应用实例生成；主要覆盖请求和参数，不能替代人工补充的响应及错误协议。
- [完整空库 DDL](schema.current.sql)：含运行时按需创建的表；只供结构对照/空库重建，不是旧库升级脚本。
- [源文件指纹](source-manifest.json)：核心源码、配置和产品文档的 SHA-256，用于识别文档是否落后于代码；不包含业务数据、会话或密钥。
- [文档检查脚本](validate_docs.py)：离线检查及重新生成指纹，不访问真实业务数据库。
- [文档检查结果](validation.json)：链接、图清单、离线协议及 DDL 对照的检查范围见评审文档。

图采用内嵌 Mermaid，可在支持 Mermaid 的 Markdown 阅读器中显示、修改和导出。源文件直接保留图定义，不依赖远程图片链接。

## 如何区分事实和设计

- **当前实现**：以代码和生成的 schema/API 附件为证据；已有代码不等于本轮真实来源测试通过。
- **规划**：人员统一身份、目标专属持久草稿、实际发送、投递回执和自动回复等扩展，不存在于当前可调用协议中。
- **已纠正文档**：交叉评审发现的描述不准确或设计歧义已修改，不等于对应业务缺口已写代码。
- **待验证**：真实城市召回、人员识别准确率、平台会话有效性和容量指标，需要专项实验。
