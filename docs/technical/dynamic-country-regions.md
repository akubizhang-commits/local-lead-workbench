# 按国家配置的地区选择与南非目录

## 目标与口径

市场创建页按国家及所选行政分支展示需要的选择器，自动生成任务名称。地区字段用于确定检索范围。国家行政制度并不总是严格的单父节点树，不能仅用一个固定的“层级数”控制表单。

本次非洲样本选择南非，指标为与中国的双边货物贸易总额，而非服装进口规模。中国驻南非使馆于2025年6月16日公布：南非连续15年为中国在非洲最大贸易伙伴，2024年双边贸易约占中非贸易20%。这不是对2026全年贸易的预测。

研究来源：
- 中国驻南非使馆：https://za.china-embassy.gov.cn/eng/dshd/202506/t20250616_11649639.htm
- 南非政府省份：https://www.gov.za/provinces
- 南非政府地方制度：https://www.gov.za/about-government/government-system/local-government

政府地方制度页面列明9省、8个大都市自治市、44个地区自治市和205个地方自治市。大都市自治市与地方自治市是本产品可选的末级市场范围；选区（wards）不作为本轮市场选择层级。自治市可能包含多个城市或乡村，不等同于单个城市。

## 页面路径

| 国家 / 分支 | 选择顺序 | 行为 |
|---|---|---|
| 美国 | 国家 → 州 / 特区 → 县 / 同级地区 → 城市 / 居民点 | 县可不选；跨县城市检索完整地点 |
| 南非大都市 | 国家 → 省 → 大都市自治市 | 第三级结束，不显示第四级 |
| 南非普通地区 | 国家 → 省 → 地区自治市 → 地方自治市 | 地区筛选后只显示所属地方自治市 |
| 未收录国家 | 国家代码 → 州 / 省 → 城市文字 | 保留手填兼容，范围未验证 |

切换国家、省或地区会清空所有下级选择。菜单显示中文层级名，地区实际名称保持来源名称。表单中不再要求市场名称。

## 配置与接口

`leadworkbench/datasets/region-configs.json` 声明 country、name、mode、labels、levels、terminal_subtypes、scope、dataset、attribution、hint。配置区分可选的县筛选与自治市分支。将来同类三层国家可通过 levels 省略 county，不需要增加国家名称判断。

`GET /api/region-configs` 返回全部配置但隐藏本地 dataset 文件名；沿用本地接口访问边界。`GET /api/regions` 仍接受 parent_id、kind、county_id。根返回国家，国家下返回省 / 州，省下按 kind 返回中间地区或末级地点。南非地方自治市的 county_ids 是所属地区，大都市自治市为空。

存储沿用 task_geography 扩展表，国家目录由本地只读数据提供，清空业务数据不会清空地区目录。历史字段 state 表示一级地区，city 表示末级市场名称，避免破坏旧客户端；真实类型与范围由 geography.place_type、geography.scope、geography.country 标明。南非范围为 whole_municipality，美国为 whole_place。检索去重使用国家和地区ID，同名不同省保持独立。

后端校验国家、省、地区、末级地点的归属。南非地方自治市必须选择所属地区；大都市自治市不允许绑定地区；错误归属不能创建任务。

## 检索范围

有来源坐标的目录可提供参考范围分区检索；没有坐标的地区按完整行政名称进行文字检索，并明确标为范围定位未完成，不将自治市强行解释成同名城市，也不声称行政范围完整覆盖。任务中的地图结果仍需业务匹配与去重。

## 验证

测试覆盖美国目录不回退、南非目录总数和归属、跨国家ID拒绝、两种南非路径创建与去重、配置接口、三层配置、层级切换、任务名称、无坐标降级。使用临时数据库验证，不向用户业务库注入测试市场。

## 本地目录来源与更新

实际导入：南非财政部 `https://municipaldata.treasury.gov.za/api/cubes/municipalities/facts?pagesize=1000`，结合 `demarcation_changes/facts?pagesize=1000` 排除35条已撤销记录。源码脚本为 scripts/import_za_geography.py；默认输出 leadworkbench/datasets/za-geography-2026.json.gz。267条地区记录包含国家本身。原始短名称保留 source_name，显示名称补充自治市类别后缀，不声称独立核验了法律全称。

目录版本2026是本地发布版本；上游 municipalities 的 last_updated 为2026-07-30T09:26，变更表版本为2016-12，相关撤销生效日为2016-08-03。不能据此声称边界已核验至2026。源快照及SHA256记录于目录metadata；默认重放缓存，`--refresh` 明确重新下载，数量或关系改变时停止输出并等待适配。

当前目录不含南非边界坐标，所以南非任务使用文字检索并报告范围定位未完成。美国已有坐标检索不受影响。
