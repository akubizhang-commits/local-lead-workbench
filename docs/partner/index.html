进入系统

帮助海外获客团队，从一个目标市场找到可联系的企业

寻迹线索工作台按“国家 / 城市 + 行业或关键词”定义目标市场，从地图上的公开商户信息发现企业，再复核企业官网和社媒公开资料，整理出可联系的入口，经人工审核后导出，并按月持续更新。

适用：做海外获客的 B2B 团队外贸业务员 / 海外销售 / 市场负责人当前为体验版

01解决什么问题

开拓一个新的海外市场时，团队通常会遇到三类麻烦。

找企业难

目标城市里有哪些相关企业，靠人工搜索费时，结果零散、重复多。

找联系入口难

官网、社媒上的信息分散，不容易分清哪个是采购、哪个只是通用邮箱或表单。

保持更新难

名单整理一次很快过时，难以知道这次新增了谁、哪些资料变了。

主要价值

  • 一个流程完成“发现企业 → 找联系入口 → 人工核实 → 导出”。
  • 联系入口按等级区分，并说明缺少更好入口的原因，便于决定先联系谁。
  • 每条资料都能看到来源和时间；人工修改不会被后续更新覆盖。
  • 市场长期累积、按月更新，清楚区分本轮新增与已有企业。

02核心功能

以下均为当前版本已有的功能，实际结果取决于公开来源能读取到的内容。

目标市场

定义要开拓的市场

选择国家、州 / 城市，填写行业或关键词。提交前可预览检索词和预计查询次数。

地图检索

发现目标企业

按城市分区和检索词，从地图上的公开商户信息中发现相关企业，每一轮的进度和结果都有记录。

官网复核

提取公开联系入口

读取企业官网的联系、关于、团队等页面，按等级整理：具名采购、相关岗位、部门邮箱、通用邮箱、表单、电话；没有更好入口时说明缺口原因。

社媒

账号发现与公开资料

查找企业在 Facebook、Instagram、X 上的候选账号，读取公开的基础资料。

待审核

审核与降噪

不确定的联系人和字段变化进入待审核，由人工确认；自动过滤招聘等明显无关的入口。人工修改受保护，不会被采集覆盖。

企业库

统一管理企业

按市场、类别、联系入口等筛选；显示来源类别，支持排除规则，区分企业实际所在城市与邻近城市。

导出

导出名单

导出联系入口表，支持 CSV 和 XLSX，按当前筛选导出全部匹配记录，在后台生成后下载。

轮次

月度计划与本轮摘要

可为市场开启按月更新的计划；每一轮显示本轮新增、已有企业和资料变化。

备份

备份与恢复

可随时创建备份，也可从备份恢复；恢复前会自动备份当前数据。

账号

账号登录

使用管理员创建的账号密码登录，网页上没有公开注册入口。

03使用流程

六步完成一个市场，之后按月重复更新。

  1. 建市场国家、城市、行业或关键词
  2. 地图检索发现目标城市的相关企业
  3. 官网复核整理公开联系入口
  4. 审核人工确认联系人与资料
  5. 导出CSV / XLSX 联系入口表
  6. 按月更新只看本轮新增与变化

第 6 步会回到第 2 步：同一个市场长期累积，重复发现的企业只更新，不重复建档。

04系统架构（当前版本）

用户只需要浏览器。所有处理和数据都在为该客户单独部署的云服务器上。

部署形态

  • 每位客户一套独立环境，部署在 AWS 新加坡区域。
  • 不同客户的数据按部署隔离，互不可见。
  • 同一环境内的账号看到相同的数据。

安全

  • 账号密码登录，账号由管理员创建。
  • 全程 HTTPS 访问。
  • 密码只保存加盐哈希，不保存明文。
  • 登录失败过多会被限速。
  • 数据只存放在该客户的环境中；不调用第三方付费模型。

数据

  • 每天自动备份，并保存到同区域的云存储。
  • 也可在网页上手动创建备份或恢复。
  • 单台服务器、没有多机热备；极端情况下以最近一次每日备份为准恢复。

05规划中的架构

以下内容是规划，尚未上线，范围和顺序仍可能调整。

原则：能放在云端的都放在云端；用户电脑上只放一个很小的本机助手，专门处理需要登录账号的社媒读取。

云端核心 + 本机助手

  • 业务规则、数据库、官网复核、计划、导出和备份都留在云端。
  • 本机助手只负责社媒账号登录和登录后的读取，回传读取结果，登录状态和 Cookie 不离开用户电脑。
  • 用户仍然通过浏览器使用工作台。

地图检索与后续方向

  • 地图检索默认在云端执行。
  • 云端访问受限时，可以按市场切换到本机助手执行，之后也可以切回云端。
  • 先做手动切换，之后再考虑自动切换。
  • 更远的方向是多租户：多个客户共用一套服务，数据仍然互相隔离。

06当前状态与说明

  • 目前是体验版，功能和界面仍在调整。
  • 目前只在 macOS 和云服务器上验证过。
  • 地图结果会混入少量不相关或邻近城市的企业，需要人工筛选相关性。
  • 部分企业官网只能部分读取，已读取到的内容会保留。
  • 服务器版暂不支持登录社媒账号读取，只读取社媒公开资料。
  • 不保证找到某个城市的全部企业，也不保证联系方式完整或准确；结果需人工核实。
  • 使用公开数据需遵守各平台条款与当地法规，由使用方负责确认。
