# 寻迹：UI设计文档

版本：1.1｜2026-09-25 市场社媒进度更新  
配套：[PRD](overseas-lead-acquisition.prd.md)｜[交互设计](interaction-design.md)

本稿整理当前视觉实现并定义建议目标规范。市场社媒进度已实现，隔离端口 18766 已验证并行/登录/详情及 375px 布局；评审问题已关闭，前端最终测试与构建通过。本地 18765 页面重载已确认新增字段，设置区域已展开。发送界面仍为未实现目标。

## UI-01 当前视觉基线与原则

当前：左侧导航、顶部面包屑、浅灰绿背景、白色卡片、深蓝文字和青绿操作色。企业库使用表格，企业与账号详情使用卡片/字段列表。

本轮只读截图中，企业库先展示标题、筛选、常驻解释、导出和批量操作，再进入企业数据；在约1265×714的窗口中，仅能看到少量企业行。问题主要是信息密度和层级，不需要更换品牌风格。

建议原则：

1. 让“目标企业、联系人、下一步联系动作”占据主要空间。
2. 维护、诊断、证据全文和历史按需展开。
3. 普通业务入口仍有价值，但不伪装成采购联系人。
4. 用清楚的文字说明状态，不依赖颜色。
5. 数值和日期有口径，未知显示“未记录/未尝试”，不能自动显示0。

UI/UX技能的通用检索参考没有直接采用：其营销官网式布局、字体和徽章建议不适合本项目的数据工作台。以下规范基于现有页面及获客流程。

## UI-02 布局与密度

建议桌面基准：1440px；兼顾1024px和窄窗口。移动端优先支持查看与简单跟进，不把复杂批量编辑硬塞进四列表格。

| 区域 | 建议规范 |
|---|---|
| 导航 | 桌面200–224px；图标配文字；企业子详情仍选中企业库 |
| 顶栏 | 56–64px，面包屑为主；服务状态收敛为可展开信息 |
| 页面内容 | 水平间距24–32px；段落与分区用16/24px间距 |
| 标题 | 页面24–28px，分区18–20px；减弱装饰性英文编号 |
| 企业表格 | 常规行56–72px，按需要允许双行；避免大段说明占首屏 |
| 联系人表格 | 四列，长账号允许合理换行；不以增加列解决所有问题 |
| 详情字段 | 标签与值对齐；标签固定宽度，值可换行；来源置于副信息区 |
| 表单 | 标签在上，字段提示在下；错误紧邻字段 |
| 批量操作 | 有选择时突出工具栏；始终说明所选范围 |

交互设计中保留的“每页50家”是当前分页，不是市场采集数量上限。

## UI-03 色彩、字体与可读性

当前CSS基线：

| Token | 当前值 | 用途 |
|---|---|---|
| 主文字 | `#233346` | 标题和正文 |
| 次要文字 | `#7A858B` | 标签、提示、日期 |
| 主操作 | `#247A70` | 主按钮、强调 |
| 深色 | `#203548` | 品牌、重点文字 |
| 背景 | `#F5F6F3` | 页面 |
| 卡片 | `#FFFFFF` | 表格、面板 |
| 分割线 | `#E4E8E5` | 边界 |

建议：保留主色，增加更深的次要文字色，例如`#53636B`；风险提示和证据文字不能仅使用浅绿。表格正文14–16px，辅助信息原则上不低于12px。对于关键状态、不可逆动作说明和错误提示，不使用10px级字体。

内部验收目标：普通文字与背景对比度至少4.5:1；可交互焦点清晰、标签完整。此为建议质量门槛，不是已经完成无障碍合规认证。

静态CSS计算发现：`#7A858B`对白底约3.78:1；部分提示约2.64:1，候选徽标约3.09:1。还需对实际叠加背景、字号和禁用状态逐项复核，不能仅换一个变量就宣布全部合格。

字体沿用系统无衬线栈；本地产品不必为了视觉装饰引入远程字体。电话、邮箱、账号和日期保留易读文本，不改成不可复制的图片。

## UI-04 页面结构示意

以下为建议线框结构，不是当前页面截图。

### 市场详情：并行资料补全

沿用 `TaskWorkflow` 的紧凑纵向行和 `WorkflowHint`，不另造社媒仪表盘。阶段显示 1 规划、2 Maps、3A 官网、3B 社媒、4 结果汇总，并明确 3A/3B 并行；仅社媒轮次省略规划、Maps、官网行。

每行保留阶段、执行结束数/当前总量、单位和剩余量；社媒主行及平台明细均用“家企业”，完整逐项报告用“项”。绿色表示成功，棕色表示已结束的异常，待处理保留灰色；正常无结果包括在成功中，不另叠加进度条。总量动态变化，不增加总体 100% 或固定剩余时间承诺。

2026-09-26：已结束的大步骤显示“已完成／部分已完成／未取得结果”，不使用“有未完成项”暗示外部网站必须重试成功。官网明细按企业汇总已读网页、未读到网页及主要原因；未解析文件独立说明。实际排队、运行、冷却、暂停和取消仍分别展示，不能用完成标签覆盖。

平台明细与完整报告默认折叠；登录、连接处理和恢复入口及其原因保持可见。Facebook/Instagram/X 分别显示等待登录、会话释放、冷却、配置、排队或执行状态，不能用一个“社媒失败”覆盖所有平台。每个等待时间附队列条件；禁用恢复按钮不能只靠颜色表达。账号和帖子成果用次级统计，避免与去重企业数相加。

“补充社媒资料”是独立显式按钮；“保存后续设置”文案明确不执行当前补充。窄屏继续使用现有上下排列和可换行原因，外部链接只由用户显式打开。具体交互见 [IX-02](interaction-design.md#ix-02-创建与维护市场)。

## UI-05 联系人/账号行组件

关联IX-04、05。

- 主标题顺序：真实姓名或账号展示名 → 用户名/邮箱 → “名称未采集”。不使用页签标题“(4) Facebook”或随机数据库ID作主标题。
- 平台名称明确写Facebook、Instagram、Twitter（X）；官网邮箱的渠道是“邮箱”，来源才是“企业官网”。
- 企业关系显示实际意义，例如“采购人员”“采购部门”“关键员工·负责人”“品牌入口”“岗位未明确”；“已采集”不是关系。
- 更新时间表示资料实际观察时间；未更新写“暂无资料更新记录”，历史入口首次入库时间放详情。
- 若数据只证明账号存在，不能出现“已确认采购”徽标。
- 真实关联的多渠道人员一行聚合，详情选择具体渠道。无法证明同人时保留独立入口。
- 多人共用邮箱不合并人员，使用“共享入口·关联N人/门店”提示并只计一次入口。采购与关键员工重叠时归采购；归属待确认的数量单列，不加入可用计数。
- 含来源冲突的字段应展示可理解的值，不直接输出数据库标识。

不重叠规则来自PRD-06；UI不能自行另算“联系人总人数”。

## UI-06 状态组件与文案

| 维度 | 推荐文案 | 不应替代为 |
|---|---|---|
| 客户匹配 | 候选企业／符合目标客户／不符合／拒绝联系 | “企业已认证” |
| 岗位 | 采购岗位证据明确／关键岗位／岗位未明确 | 泛化“已验证” |
| 账号归属 | 品牌入口／门店入口／员工／待确认／不采用 | “页面可读所以属于企业” |
| 读取 | 未尝试／读取中／已读取／受阻／保留旧资料 | “资料完整” |
| 市场运行 | 本轮检索结束／部分完成 | “已获得全城全部企业” |
| 草稿 | 草稿已保存，尚未发送 | “已联系” |
| 发送结果【规划】 | 已受理／失败／结果未知 | 无凭据的“已送达” |
| 后续投递结果【规划】 | 投递失败，附原受理时间 | 退信后仍显示“发送成功” |
| 人工记录 | 人工记录·已联系／人工记录·已回复 | 自动投递/回复回执 |

建议色彩语义：青绿为主操作，蓝灰为处理中/候选信息，深橙配浅底为待处理，深红配浅底为失败，灰色为不采用/取消。状态必须带文字，禁用不能只靠降低透明度。

同一卡片避免多个含义相近的“自动收录”“证据自动收录”徽标；采用状态、身份与采集结果分属不同位置。

待确认入口可以保存草稿；确认发送前，身份与归属区必须有明确采用依据。缺失时在预览中提供“核对并采用入口”，不以点选收件对象代替核对。结果未知的记录提供“核对结果”，没有查询能力时显示人工核对入口及说明，而不是可重复点击的发送按钮。

## UI-07 表单、操作与键盘规范

- 每个输入有可见标签；图标按钮有可读名称。
- 必填、格式错误和保存冲突分别说明，用户输入保留。
- 弹窗打开后焦点进入，关闭后回到触发按钮；支持键盘Tab、Enter和Esc。
- 禁用操作旁说明原因，例如“先选择收件对象”；只显示灰按钮不够。
- 加载中显示局部进度，避免整个详情替换导致草稿丢失。
- 长邮箱可完整复制；来源外链的点击不替代“打开内部详情”。
- 来源和旧值提示可以折叠，但不可仅悬停可见。
- 触摸场景建议主要命中区域至少44px；桌面密集表格也必须可稳定点击。
- 减少动效设置生效；不以闪烁或脉冲动画制造虚假的“正在采集”。

## UI-08 响应式与异常页面

| 宽度/场景 | 建议行为 |
|---|---|
| ≥1280px | 完整导航和筛选行；表格展示核心列 |
| 1024–1279px | 筛选折行，批量工具栏收敛；四列联系人表仍可读 |
| <780px | 导航收缩但保留可读名称；复杂表格允许明确的横向滚动，或切成语义相同的列表卡片 |
| 200%缩放 | 关键按钮、正文和来源可访问，不被固定宽度裁切 |
| 无数据 | 区分空库、无筛选结果和没有联系入口 |
| API失败 | 显示读取失败与重试，不显示虚假0数量 |
| 来源读取失败 | 已有资料仍展示，标明各自日期和最新失败原因 |
| 发送结果未知【规划】 | 显著提示核对结果，不能伪装成功或直接反复重发 |

## 2026-09-24 已实现调整

市场任务页的返回导航位于标题上方；市场操作位于概览标题右侧。状态和轮次筛选集中在列表工具栏，重置仅在有筛选时展示。复核操作位于表格最后一列，窄屏表格局部滚动；轮次详情在原生对话框展示。进入复核详情后返回保留分页、状态和原轮次。企业批量操作只在选中记录时展示。账号详情不显示企业编辑操作。

切换国家或州清空下级地域。跟进目标切换时有未保存内容须确认放弃；同一页面生命周期内返回企业/账号页保留内容，按企业隔离，不等同于刷新后持久化草稿。人工补记的回复带“人工记录”来源。完整测试结果见 `../validation/2026-09-24-prd-ui/综合测试报告.md`。


## 2026-09-24 美国地区选择器

地域四项沿用表单双列布局，先国家/州，再县/城市。州及城市支持输入检索建议；县列表含全州选项。地点建议显示官方名称与建制市镇/CDP类型；同名地点必须可区分，修饰性标签不作为后台城市名称。异步加载、失败重试和未验证文字输入分别提示。跨县市场在市场列表/详情标明完整城市范围。
