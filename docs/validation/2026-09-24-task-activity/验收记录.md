# 失败日志审查与任务列表验收

日期：2026-09-24。

## 审查范围与结果

完整扫描当前业务库的14条普通运行、179条网站/地图工作项、16条社媒运行、913条社媒工作项，以及应用运行日志。各工作项可能命中多个问题类别，父运行摘要与子项错误不重复累加。没有将历史失败记录修改为成功，没有批量重新爬取，也没有发送消息。

完整分类和证据：[失败日志审查](../../audits/2026-09-24/failure-log-review.md)。

主要共性问题：

- 图片、Atom/RSS、商品目录等无关资源进入网页抓取，浪费预算并产生格式错误。新增图片/订阅资源过滤，覆盖新发现、检查点恢复及重定向；PDF保持“未解析文件”，不伪装成HTML成功。
- TimeoutError等异常的文字为空，日志只有冒号。网站、Maps、规划和工作项异常均保留异常类型；规划内部已具备的类型保留逻辑经检查无须重复修改。
- Maps子进程正常退出不等于成功：stderr中的浏览器关闭或闲置超时曾可能误判为检索穷尽。现在根据已确认的结构化错误识别，保留有效企业并标记部分完成/需要处理，不误报已完整覆盖。
- 403、robots、证书和网络问题、搜索服务不可用、社媒不支持或需要登录均属来源能力/环境问题，不能用隐藏错误或关闭安全校验解决。已有社媒共享来源暂停机制仍保留；不会把所有暂停项解释为独立平台事故。新错误展示给出分类说明。
- 3条已成功复核工作项仍保存11条旧失败事件。保留审计历史，但详情明确历史尝试与当前结果的区别，不按旧日志将完成任务重标失败。

## 交互验收

- 首页改为市场检索任务列表。
- 点击市场后查看所有企业复核工作项，支持状态筛选、轮次筛选及每页50项。
- 单独复核按当前市场成员关系关联展示，明确标注来源，不伪造属于检索轮次；另有独立入口涵盖所有单独复核。
- 点击企业复核进入详情，显示企业、复核结果、读取统计、网页明细、原始错误与整轮控制。
- URL保留层级，刷新及浏览器前进后退可恢复页面。没有工作项时间戳时明确展示轮次开始时间。
- 保留市场企业统计、覆盖范围、市场更新和定时计划。
- 独立代码复核发现轮次投影遗漏coverage，已补齐并对不可重试的能力耗尽轮次增加回归断言，避免显示无法执行的“继续”。

实际浏览器验证：洛杉矶市场显示7条关联单独复核；纽约市场显示153条自动复核，分页到第二页成功；筛选失败后为11条且重置到第一页。Ambiance Apparel详情能直接显示当前已完成及历史网页日志。测试期间发现详情误放入页头操作区导致横向溢出，已修复并加入App DOM回归测试；逐页日志有固定高度滚动区与折行。
