# 社媒自动发现交付与20家真实试点

日期：2026-09-22。已加载到本地工作台，API、采集worker和本地SearXNG均已启动。

## 已实现

- 设置 → 社媒自动发现：配置本机SearXNG、测试真实搜索、启动20家分层试点、查看逐项报告、取消或新建重试。
- 企业库 → 企业详情 → 社交账号与动态入口：单企自动发现、运行历史、公开预览及字段候选、原平台入口。
- 自动流程：官网提取 → 域名/名称＋城市/公开电话搜索候选 → 去重关联 → 受控读取公开页面。自动搜索首批针对Instagram、Facebook、TikTok；官网发现及公开读取适配器还覆盖YouTube、X、Pinterest、Bluesky常见链接。LinkedIn保留人工跳转，不自动读取会员资料。
- 每个查询单独记录；SearXNG成功响应、搜索无结果、上游失败、无官网未请求、robots限制、HTTP拒绝、网络超时、登录要求和仅脚本外壳分开表示。
- 同源失败会暂停该源的剩余工作；共享品牌URL复用同次运行结果。不将未执行的工作伪装成成功请求。
- 公开预览仅取可读取页面元信息；邮箱/电话必须原文出现，归属待确认。不把评论区邮箱、广告标题当作采购人员；不将预览当完整帖子。
- 搜索摘要保存查询词、原摘要、实际搜索来源，与平台原文分开。网站制作或第三方语境增加疑似第三方提示。
- 不采用决定持续生效；企业在排队后标为拒绝联系也会停止相关工作。取消后的迟到结果不能写回。重试保留原报告，进程中断后恢复待处理项。
- 最新访问失败时保留上次成功预览，并区分内容采集时间与本次访问时间。

## 当前可用性结论

本机SearXNG JSON接口能正常响应，但此次上游Google、DuckDuckGo等搜索请求超时，没有得到有效候选结果。程序正确将其标为“搜索引擎未响应”，没有伪造无结果或采集成功。

社媒公开页面没有成功取得可用预览；此次证据不足以证明登录即可解决。robots拒绝、网络失败和鉴权必须分开诊断。目前没有平台Token、OAuth连接、浏览器登录会话复用、验证码处理或登录后爬取。完整帖子流、采购意图模型、平台字段自动采用和独立社媒周期计划尚未实现。邮件、私信、评论没有自动发送。

实现与试点已交付，但当前环境尚不能提供稳定自动社媒内容补全。下一步应先解决上游搜索的网络可达性，并用单个平台验证内容读取路径，再考虑扩大采集。
