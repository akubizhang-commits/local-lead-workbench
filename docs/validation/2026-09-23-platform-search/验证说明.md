# 企业名称站内搜索验证

企业详情新增“按企业名称站内搜索”。任务只搜索 Facebook、Instagram，直接复用各平台专用浏览器目录；不调用官网、Google 或 SearxNG。最多保留每平台10个名称匹配候选，不自动确认归属或读取候选帖子。重试保留搜索模式，取消后的结果不会写入。

实测企业 Vocal Apparel：Facebook 搜索获得4个名称相关候选，1个已存在，新增3个。Instagram 检测到登录页面，未执行搜索。不能宣称两个平台均已跑通，也不能推断用户此前未登录。原始业务结果见 live-result.json。

用户在设置打开平台专用登录窗口，直接向平台输入账号密码，关闭并释放后可重试。应用不提供密码收集表单，不记录密码。登录目录仅保存在本机。

验证：后端423项通过，44个子测试通过；前端构建通过；前端测试32项通过、3项因DOM依赖缺失跳过。应用按钮至后台任务的真实流程已测试。

限制：名称匹配仅为线索，存在同名或近似名称误匹配；尚未做城市/电话自动归属验证。Instagram站内搜索适配仍需有效登录会话实测。页面空白或不识别返回受阻而不是假报无结果。
