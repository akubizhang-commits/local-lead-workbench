# 联系人全库检查与过滤规则修正

日期：2026-09-23。

检查的是本地已保存资料及来源证据，不是重新访问所有官网，也不是邮箱投递验证。

范围：274 家未合并企业，1,090 条联系人源记录。其中 88 家企业有尚未归档的联系人，共 1,066 条（跨来源重复计入）；无联系人记录的企业没有可检查的联系人字段。

本轮归档 39 条自动提取记录：

- 28 条无供应商申请/联系意图的供应商入口：文章、商品分类、运输政策、首页及代发业务宣传。
- 4 条错误姓名：Cookie 提示、宣传句、拼接了职务的员工姓名。
- 2 条错误岗位：Buyer Join 导航文案、Fabric Sourcing 服务内容。
- 2 条 GoDaddy 占位邮箱。
- 3 条非来源网站自身的 StarApps / accessiBe 技术服务邮箱。

归档保留原记录与 changes 审计记录；不删除来源。人工已接受/排除的记录受到原有保护。原始检测清单（原始证据已归档，不随交付），清理结果见 after.json。

过滤规则由官网提取和存量清理共用。真实 Buyer、Sales Manager、少见姓名、个人邮箱、供应商注册及供应商门户的正向用例继续通过。名称或岗位误归属时，原文明确发布的有效邮箱仍可保留为企业通用渠道；占位邮箱和第三方插件邮箱不会被重新保留。

清理后剩余 1,027 条当前源记录，对本次两套字段质量规则复查未发现残留。此结论不证明联系人任职、所有权、用途、邮箱可投递性或未访问页面的信息准确性，也不包含全库社媒账号归属重新核验。

验证：443 个后端测试通过，44 个 subtests 通过；2 个依赖弃用警告。本地服务已重启使用新规则。
