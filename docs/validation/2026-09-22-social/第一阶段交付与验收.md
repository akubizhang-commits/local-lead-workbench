# 社交账号与企业补全：第一阶段交付

日期：2026-09-22。已加载至本地工作台。

## 使用入口

企业库 → 企业详情 → 社交账号与动态入口，位于公开联系人之后。

1. 账号入口与帖子/合集分开显示，帖子默认折叠；打开账号或原帖不记录已联系。
2. “查看发现证据”显示来源与时间。缺少字段来源的历史链接明确标注，人工录入明确标注。
3. 选择品牌统一账号、此门店、企业员工或第三方提及，再确认归属；不采用的记录单独折叠，可恢复待核对。
4. “查找更多账号 / 添加候选”提供官网域名、企业名＋城市、业务电话及数字格式的搜索入口；在搜索页面人工选择结果后粘贴链接。
5. 确认归属后，可保存草稿、已联系、已回复、结束跟进记录。非草稿状态需勾选已实际发生。页面不发送任何私信、邮件或评论。
6. 同一链接关联的企业共享查看跟进历史；拒绝联系的企业不能新增跟进。历史记录保留。

## 采集与数据

启动时迁移已有企业社交链接，原始数据保留。后续官网采集在同一事务中同步社交链接；“整理已有链接”不触发外网访问。官网结构化Organization/LocalBusiness/Store/ClothingStore/Corporation声明的sameAs，在声明官网域名与来源一致时作为候选提取；不将Person或其他企业声明当作企业账号。

社交模块分为规范化链接实体、企业关联、发现证据、人工决定历史、跟进记录。按规范化URL去重，去除追踪参数，保留影响身份的参数。支持Instagram、Facebook、LinkedIn、YouTube、TikTok、X、Pinterest、Bluesky常见主页和帖子路径；未知路径、短链接等保守过滤。不读取平台稳定ID，因此不同handle/频道ID别名尚不能保证合并。

所有迁移账号均为候选，没有自动宣称已核实账号所有权。不采用不会被官网同步覆盖。已有企业信息没有因该迁移相互覆盖。

上线快照：75家企业有社交关联；276个去重后的账号候选URL、64个帖子/合集URL、376条企业与链接关联。它们是已有数据整理结果，不是本轮外部检索新增企业数，也不是已验证账号数。

Fashion Atlas Group展示5个账号入口、8个帖子链接，均尚未人工确认归属。后台采集在线。
